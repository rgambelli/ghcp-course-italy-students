# GHCP Training Students

This repository contains the materials for the students of the hands-on GHCP training.

## Prerequisites

- Follow module 1 and module 2 of part 1 of the Microsoft GHCP training: https://learn.microsoft.com/en-us/training/paths/copilot/
    - Module 1: https://learn.microsoft.com/en-us/training/modules/responsible-ai-with-github-copilot/ (required by legal)
    - Module 2: https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/ (Good and practical introduction to GHCP)
- Working GHCP license (and a Cegeka linked GitHub account)
  - Make sure you have access to the correct organization: Cegeka-Application-Services (https://github.com/Cegeka-Application-Services)
    - At the time of writing there were 2 organization and a slow migration from one to the other was being executed
- GitHub Copilot enabled in your IDE (VSCode, IntelliJ, etc..)
    - Update your IDE and Plugins to the latest version
    - Install the Mermaid plugin in your IDE 
- Your coding environment is set up and ready to go
    - Checkout the course repository
    - Open lab 1 in your IDE
    - Run the PrerequisiteProjectTest to verify everything is working correctly (the test should pass)
        - Java: you will need to install java 25
