# GHCP Workshop Students

This repository contains the material used in a workshop focused on the practical use of Microsoft Copilot for software development.

The project is designed as a training path composed of six hands-on labs. Each lab explores a specific capability or usage pattern, helping participants learn how to work more effectively with Copilot in realistic development scenarios.

## Repository Structure

The repository is organized by technology branch.

### Current Branches

- java: currently available
- .net: planned for a future iteration

At the moment, the java branch contains the workshop material. In this branch, the six labs are implemented as six distinct Maven projects.

In the future, the same learning path will be replicated in the .net branch, with equivalent labs adapted to the .NET ecosystem.

## Training Goal

The purpose of this repository is to provide guided, practical material for a workshop centered on Microsoft Copilot. The labs are intended to help students progressively improve how they interact with Copilot by learning:

- how to write effective prompts
- how to provide relevant context
- how to use instructions to guide the assistant
- how to work with custom agents
- how to define and use skills
- how to integrate MCP servers into their workflow

## Labs Overview

### Lab 1 - Prompting

Focuses on prompt writing.

Participants learn how prompt quality affects Copilot output and how to ask for code, refactoring, tests, or explanations more effectively.

### Lab 2 - Providing Context

Focuses on enriching prompts with the right context.

Participants learn how to improve Copilot results by supplying relevant code, requirements, constraints, or surrounding architectural information.

### Lab 3 - Instructions

Focuses on instructions.

Participants learn how persistent or scoped instructions can shape Copilot behavior and help obtain more consistent outputs aligned with project expectations.

### Lab 4 - Custom Agents

Focuses on custom agents.

Participants explore how agents can be tailored for specific workflows or responsibilities, such as documentation or specialized development support.

### Lab 5 - Skills

Focuses on skills.

Participants learn how to define reusable capabilities and guidance that Copilot can load and apply to recurring tasks.

### Lab 6 - MCP Servers

Focuses on MCP servers.

Participants explore how MCP servers extend Copilot by connecting it to external tools and systems, enabling richer and more contextual workflows.

## Prerequisites

Before starting the workshop, participants should have:

- completed module 1 and module 2 of part 1 of the Microsoft GHCP training:
    - Responsible AI with GitHub Copilot
        https://learn.microsoft.com/en-us/training/modules/responsible-ai-with-github-copilot/
    - Introduction to GitHub Copilot
        https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/
- a working GHCP license
- GitHub Copilot enabled in their IDE
- a development environment ready to run the labs
- access to the appropriate GitHub organization, if required for the training setup
