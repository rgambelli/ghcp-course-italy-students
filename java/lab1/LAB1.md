# Lab 1

## Lab 1.1: No context, one prompt
- This project contains code for the start of a simple mailbox application
- There are user stories defined in [LAB1_STORIES.md](LAB1_STORIES.md) and we want GHCP to implement these stories
    - Q: Which mode would you use to implement them?
- Read the stories and take a look at the code
- Only once you understand everything, try to have GHCP implement all the stories using 1 simple prompt with a low cost model
    - There is no need to improve the code manually
    - If the result is complete garbage, rollback and try again with 1 simple prompt
- Quality check: Imagine you are the techlead on your project and you want a high quality result
    - Are all the stories implemented correctly?
    - Do the tests work?
    - Do the tests cover all the functionality?
    - Do the tests cover sufficient edge cases?
    - Check the quality of the code in general
        - Maintainability, readability, structure, single-responsibility...
    - ...

- Continuing on the result from lab 1.1, try to improve the result by iteratively prompting GHCP until you reach a satisfactory result
