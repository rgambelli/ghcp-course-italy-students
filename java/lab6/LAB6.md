# Lab 6

- Install the GitHub MCP server 
  - VSCode: from the marketplace
    - Command palette > `MCP: Browse MCP Servers`
    - Search for `GitHub` ("Connect AI assistants to GitHub - manage repos, issues...")
    - Click Install
  - IntelliJ: from the built-in MCP registry search
    - Click the `MCP Registry icon` in the GHCP chat at the top right ('crooked M' icon)
    - Search for `io.github.github` ("Connect AI assistants to GitHub - manage repos, issues...")
    - Click Install
- Follow the authentication steps
- Write a prompt to find the hidden password in a GitHub issue with "Lab 6" in the title

To view your currently configured MCP servers (`mcp.json`):
- VSCode: Command palette > `MCP: Open User Configuration`
- IntelliJ: Open Settings | Tools | GitHub Copilot | Model Context Protocol (MCP) > Configure
